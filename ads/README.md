# 광고 소재

랜딩페이지 번호를 그대로 따른다. `1.html` → `1-1`, `1-2`, `1-3` …

| 파일 | 크기 | 용도 |
|---|---|---|
| `1-1.svg` | 1200×628 (1.91:1) | 페이스북 피드 링크 광고 |
| `1-2.svg` | 1080×1080 (1:1) | 모바일 피드 · 인스타그램 |

이 폴더에는 **수정용 SVG 원본**만 둔다. 실제로 광고 관리자에 올리는 JPG는
저장소 루트에 `1-1.jpg`, `1-2.jpg`로 배포되어 있다.

## JPG 다시 뽑기

SVG를 고친 뒤 헤드리스 크로미움으로 같은 크기로 다시 추출한다.
뷰포트가 창 크기보다 작게 잡히는 문제 때문에 `--screenshot`은 하단이 잘린다.
CDP `Page.captureScreenshot`에 `clip`을 주어야 정확한 크기가 나온다.

## 문구 원칙

이미지 안에는 근거가 필요한 내용을 넣지 않는다.

- 수익 금액, 합격률, 취업률
- 모집 인원, 마감 시각 등 실제로 관리되지 않는 긴급성 문구
- 사이트 기능을 흉내내는 가짜 버튼 · 재생 아이콘 (메타 광고 정책 위반)
